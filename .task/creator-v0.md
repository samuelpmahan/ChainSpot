## Contract
- Reusable DiscCard and manually manipulated DiscBattle; basic reusable local collection.
- A physical disc has its own identity and exact uploaded photograph; mold facts are values.
- Scores belong to battle entries, not discs. Editing selection is not on-screen emphasis.
- No assumed scoring scale, automatic winner, throws, timing, map, CV, accounts, catalog, or video editor.
- Additive static subapp; preserve every existing upstream file and route.

- Screenshot and personally inspect the real browser and clean overlay at 1920 and 1280 video sizes.
- Actual proof artifacts, precise run instructions, and an applicable Git checkpoint.

# Logistic classifier coefficient maps (ASCII)

Generated by `scripts/nuthing/visualize-logistic.ts` from `resources/nuthing-p2/digits/models/logistic.json` (variant 1, real-only train). Each block is one class's learned weight row `W[k]` reshaped back to its 24x32 spatial layout (row-major, same orientation as the normalized mask). Bucketing is per-class, relative to that class's own max |weight| (strong >= 0.66x max, weak >= 0.15x max):

- `#` strong positive (ink here strongly favors this digit)
- `+` weak positive
- `·` ~zero (this pixel carries little evidence either way)
- `-` weak negative
- `=` strong negative (ink here strongly argues against this digit)

## TOP 10 across G0-G3 + shared infra (ranked)

1. **g3.teeFamily.ts `selectTeeFamily`** — single-largest-size-family clustering discards every genuinely-correct tee that doesn't match the course's dominant rendered scale (self-admitted dataset-fit calibration in-code). *Fix direction:* replace "reject everything outside the winning family" with per-candidate acceptance against a size prior derived from the basket-sprite/badge scale actually observed in *that* image (already available), so a legitimately differently-scaled tee is evaluated on its own merits instead of voted out by majority.
2. **endpoints.ts / g2.sprite.ts fixed 42×66 basket sprite** — one hard-coded bitmap size+rotation for the only object class with a rigid render footprint in the whole detector. *Fix direction:* derive the expected sprite scale per-image from a self-calibration pass (e.g. measured badge plate size, which already varies and is handled correctly) instead of a committed asset constant.
3. **smartBasket.ts `searchSeed` window pinned to the seed's own bbox** — occlusion-recovery search geometry structurally cannot look beyond a badge's/basket's own footprint, mirroring the confirmed G4 exemplar one gate earlier. *Fix direction:* widen the search window to a course-local basket-to-badge offset prior (measured from already-accepted pairs in the same image) rather than a template-width-derived box.
4. **g3.teeRecovery.ts predecessor-chain recovery** (owner-confirmed exemplar, reinforced with exact mechanism: `targetPredecessors` has no fallback when hole N-1 is unassigned or absent) — cascading, permanently unrecoverable failure for hole 1 and any non-adjacent numbering scheme. *Fix direction:* add the same badge-diagonal fallback g3.phantomTee.ts already has, so a missing predecessor degrades instead of forecloses.
5. **screenChrome.ts bottom-only chrome anchor**, self-documented as tuned on 5 rasters from one course ("AlexClark"), with a hard-coded assumption that all screen chrome anchors to the bottom edge. *Fix direction:* generalize chrome-region detection to any image-edge anchor (top/left/right too), and expand the tuning corpus beyond one course before calling the heuristic general.
6. **g0/stripChrome.ts `looksLikePortraitPhone` gate** (`heightPx>=1000 && widthPx>=500 && height>width`) — silently skips ALL single-image chrome stripping for any capture that isn't a tall portrait phone photo. *Fix direction:* run the entropy-boundary scan regardless of aspect ratio/size, or explicitly fail loud ("chrome stripping skipped: unrecognized capture shape") instead of silently passing raw chrome through as canonical.
7. **g0/stitchSolve.ts left-to-right-only tile layout + tile-0 semantic anchor** — assumes a single capture order and a badge-bearing first tile. *Fix direction:* accept an explicit capture-order/orientation hint from the caller, and pick the semantic anchor as whichever tile has the most badges rather than always tile 0.
8. **g3.phantomTee.ts predecessor-basket-tip primary path** — restates exemplar #1 one layer up (assignment completion). Lower urgency than #4 since it already has a real fallback and is default-OFF. *Fix direction:* none additional beyond #4's fix, since fixing the shared worldview fixes both call sites.
9. **shared.hsv.ts / raster.ts `brightVMin:210, brightSMax:45, darkVMax:45`** — properly knobbed but is the single highest-blast-radius constant in the detector (every downstream gate depends on it) with no self-calibration against the actual image's rendering theme. *Fix direction:* add an optional auto-calibration pass (histogram-derived bright/dark split per image) with these as a documented fallback, rather than a universal global constant.
10. **g0/stripChrome.ts entropy-detector literals** (`ENTROPY_THRESHOLD_RATIO=0.74`, `MAX_INSET_FRACTION=0.25`, etc.) — bare, unknobbed, dataset-tuned. *Fix direction:* thread these through the same ABFeature knob pattern used everywhere in threeFactor/, so at minimum they're documented and overridable, and cap-fraction failures are logged instead of silently truncated.

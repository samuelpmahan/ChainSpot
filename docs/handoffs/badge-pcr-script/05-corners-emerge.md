# PCR 5 — shared corners emerge

With live ownership corrected experimentally and digit residue treated separately, mute the digit regions and align the remaining badge crops in a common badge frame.

Across the course population, the strongest repeatable residual is not a digit pattern. It is the rounded frame/corner structure:

- four corner crescents recur strongly;
- a thin rim around the outer frame also recurs;
- these features persist across multiple courses;
- the support map is computed from repeatable non-neutral RGB, not mere bbox coverage.

This checkpoint does not reinterpret the corners as a universal compositor law. It records the empirical fact that a shared frame residual emerges once digit structure is muted.

The important PCR property is that the shared structure appears from population alignment rather than being drawn in advance. Every contributing badge remains inspectable so the claimed shared support can be challenged against its instances.
